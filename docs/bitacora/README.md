# Bitácora

Registro de decisiones y aprendizaje del proyecto, versionado junto con el código. Un archivo por fecha (`YYYY-MM-DD.md`). Formato libre pero cada entrada debe capturar: qué se decidió, por qué, y qué queda pendiente — para que un agente (o tú en 6 meses) pueda reconstruir el contexto sin releer el chat completo.

Cuando esto se conecte a Nextcloud como memoria de agentes (fase futura), este directorio es la fuente de verdad; Nextcloud será una vista/sincronización, no el origen.
