# 2026-08-30 — Tracing distribuido (Idea 7, post-roadmap)

Parte de la Idea 7 (ver `devops-multiagent/docs/29110/idea7-tracing/` para el detalle completo). Esta entrada es solo el lado de este repo.

## Cambio
`tracing.py` (nuevo) configura un `TracerProvider` de OpenTelemetry apuntando a Jaeger (OTLP/gRPC, `observability`), llamado en `server.py` junto al resto del arranque. **No hizo falta instrumentar cada tool a mano** — el SDK de MCP (`mcp[cli]>=2.1.1`) ya trae un middleware de OpenTelemetry embebido que envuelve cada `tools/call` en un span y extrae el `traceparent` del `_meta` de la request automáticamente.

## Verificado
Trace real de punta a punta (`uv run devops-agent diagnose "..."` desde `devops-multiagent`): el span `tools/call list_nodes` de este servicio aparece correctamente anidado bajo el trace_id del Diagnostician, confirmado en la UI de Jaeger y via su API (`/api/traces`).
